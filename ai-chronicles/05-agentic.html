AI 编年史 04：智能体 (Agent) 的进化图谱

🔖本文约 795 字，阅读预计耗时 2 分钟。
ⓘ本篇整体暂不由博主构思，而是由 Gemini 自主编写，博主负责学习和校验，注意甄别。[狗头]
2026年2月14日 ·AITech History·🏷️ Agent🏷️ ReAct🏷️ AutoGPT🏷️ BabyAGI🏷️ Prompt Engineering🏷️ Chronicle

第一阶段：Prompt Engineering —— 咒语时代 (2022) ​

在 ChatGPT 刚发布时，大家还在研究怎么写 Prompt。

1.1 背景与痛点 ​

  • Zero-Shot：直接问，不管模型懂不懂。
  • Few-Shot (In-Context Learning)：给几个例子，让模型照猫画虎。这是 GPT-3 的核心卖点。
  • CoT (Chain-of-Thought, 2022)：让模型一步步思考 ("Let's think step by step")，显著提升推理能力。
    • Google PaLM (2022)：证明了 CoT 能解奥数题。

1.2 局限性 ​

  • 模型只能在内部世界里推理，无法联网，无法用计算器，无法执行代码。

第二阶段：Tool Use与 ReAct —— 睁眼看世界 (2023 上半年) ​

当 LLM 被赋予了调用 API 的能力，潘多拉魔盒打开了。

2.1 核心思想：ReAct (Reason + Act) ​

  • 论文：ReAct: Synergizing Reasoning and Acting in Language Models (Yao et al., 2022)
  • 原理：让模型先思考 (Thought)，再决定调用什么工具 (Action)，拿到工具结果 (Observation)，再继续思考。
    • Thought: 用户想查天气。
    • Action: Search("北京天气")
    • Observation: "晴，25度"
    • Thought: 天气不错。
    • Final Answer: "北京今天天气晴朗。"
  • 代表产品：
    • LangChain：将 ReAct 模式封装成了 Agent 概念。
    • ChatGPT Plugins：官方支持联网、订餐、查股票。

第三阶段：Autonomous Agent —— 自主规划 (2023 下半年) ​

如果给 Agent 一个终极目标，让它自己拆解任务、自己反思、自己执行，会发生什么？

3.1 背景与痛点 ​

  • AutoGPT：开源界的狂欢。给定目标“帮我做个网站”，它会自己去 Google 搜教程，自己写代码，自己存文件，自己测试。
  • BabyAGI：任务列表驱动。生成任务 -> 执行任务 -> 根据结果生成新任务 -> 循环。
  • Generative Agents (斯坦福小镇, 2023)：25 个 AI 在虚拟小镇里生活、社交、办派对。证明了 Agent 具备社会属性。

3.2 挑战与幻灭 ​

  • 死循环：AutoGPT 经常卡在某个步骤出不来。
  • 成本高昂：跑一个任务要烧几十美金 Token。
  • 不可靠：目前的大模型规划能力还不足以支撑长链路任务。

第四阶段：Multi-Agent —— 群体智慧 (2024 - Future) ​

一个诸葛亮不如三个臭皮匠。既然单个 Agent 不靠谱，那就搞个团队。

4.1 核心思想 ​

  • 角色扮演 (Role Playing)：让不同的 Agent 扮演不同角色（产品经理、程序员、测试员）。
  • SOP (Standard Operating Procedure)：把复杂的流程拆解成流水线，每个 Agent 只负责一小块。
  • 辩论与协作：让 Agent 互相 Review 代码，互相找茬，提升准确率。

4.2 代表框架 ​

  • MetaGPT (2023)：模拟软件公司的开发流程。
  • CrewAI：基于角色的任务编排。
  • ChatDev (2023)：通过聊天来开发软件。

5. 拓展：Agent 能力分级 (L1-L5) ​

在工程落地中，我们可以借鉴自动驾驶的分级标准：

  • L1 (规则)：规则驱动的工具调用。
  • L2 (推理)：多路径选择，决策可解释。
  • L3 (记忆)：多轮一致，失败归因。
  • L4 (泛化)：自主学习与策略复用。
  • L5 (协作)：多 Agent 协作。

级别越高，越难控制。

6. 总结 ​

Agent 是通往 AGI 的必经之路。未来的软件可能不再是人写的，而是人定义 SOP，让 Agent 团队去实现的。
